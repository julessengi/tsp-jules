# tsp-jules
TSP-JULES (Trading Smart Platform) is a modular AI-powered trading platform designed for probability-based decision making, advanced risk management, market intelligence, and automated trading workflows. Built with Domain-Driven Design, Clean Architecture, and extensible plugin support

## Vision

TSP-JULES est une plateforme de nouvelle génération destinée à assister les traders grâce à :

- Moteur de probabilité
- Gestion intelligente du risque
